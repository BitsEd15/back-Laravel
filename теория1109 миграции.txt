            Миграции и модели.


Если вручную управлять структуруой бд, отсутсвует версионирование базы данных, 
гибкое управление структурой.

Чтобы решить данную проблему, придуманы миграции.
Миграции - это файлы, в которых описывается каркас бд, каркас конкретной таблицы бд
и припомощи конкретной команды, оно применяется. 
И в случае чего, при помощи след миграции, можно отредактировать таблицу,
но только в отдельной миграции, что позволяет версионировать таблицу бд и бд в общем.

В ларавель миграции встроены по умолчанию. 
В папке database/migrations.
При создании миграций принято описывтаь суть миграций. 


return new class extends Migration - конструкция, по созданию динамических классов. 
У классов нет названия, есть только сам факт объявления класса и факт наследования
основго класса миграции. 

Каждый класс миграции состоит из 2 функций, публичная функция up
public function up(): void - void означает, что ответом данной функции является метод.
Функция up применяется, когда мы накатываем миграцию, то есть создаться таблица (например)

Публичная функция down     public function down(): void
Она выполниться, когда мы захотим бд, до какой то версии или же откатить ее вовсе,
что.

При root@d9230263c75c:/var/www/html# php artisan make:migration create_products_tabl
e - для создания миграции, нужно войти в контейнер и выполнить команду 
php artisan make:migration - команда create_products_tabl - название миграции
Важно давать иллюстративное название, которое отражает то, что мы хотим сделать.

Разбор файла миграции

public function up(): void
    {
        Schema::create('products', function (Blueprint $table) {
            $table->id();
            $table->timestamps();
        });
    }

Schema класс, используется для обозначения, что мы работаем со схемой бд.

Что таке schema? Бд делится на пространства и рабочие области. 
Например по умолчанию мы находимся в пространстве public - schema public.
Есть возможность создать новую schema private. И в ней не будет таблиц, 
которые есть в public.
В функции up, можно сразу указывать нужную schema.

В функции up описан каркас таблицы. Класс Blueprint хранит в себе нужные методы, 
связанные с типами данных. 


Когда закончили заполнять миграцию, в контейнере выполняем команду 
php artisan migrate. 

php artisan migrate:rollback - откатить миграцию. 

Если мы вручную создаем миграцию, без php artisan, важно правильнро поставить дату. 
Если хотим, чтобы приоритет был выше существующей, то дате должна быть старше.
Например таблицы категорий и продукта. Категория должна быть с датой старше 
таблицы продуктов. 


php:artisan migrate refresh - данная команда накатить новую,
обновленную структуру к баззе данных. Но сначала их удаляет. 
То есть удаляет записи и обновляет. На боевой бд, эту команду применять нельзя. 


                Модели
Модели - это удобные интерфейсы, для взаимодействия с табл бд.
Представляют они из себя php классы, которые оснащены перечнем методов. 
Для создания, также используется команда artisan
php artisan make:model Product

Чтобы менять или заполнять, добавлять значения полй в таблицу, при помощи модели.
Необходимо заполнить свойсвто класс fillable
